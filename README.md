# 声音克隆 · 有声读物工坊

本地部署的「声音克隆 + 有声读物生成」全栈应用：克隆自己/家人/朋友的声音形成独特音色（声音模型），把任意文稿变成由该音色朗读的有声读物，支持混音参数微调与在线试听，全部数据本地存储。

```
声音克隆（训练/微调/润色音色）
        │
        ▼
文稿导入 → LLM 润色（可选）→ 初版音频 → 克隆音色混音 → 参数微调 → 在线试听 → 渲染成品
                                                                    │
                                                    全部存储在本地磁盘
```

## 功能

| 功能 | 说明 |
|---|---|
| 🎙️ 声音克隆 | 上传 10~60s 参考音频，零样本克隆独特音色（GPT-SoVITS 本地 GPU / MiniMax / Fish Audio 云端） |
| 📄 文稿润色 | 导入 txt/md/srt，调用 LLM（默认 DeepSeek V4-Flash，约 ¥4/16 百万token）润色为适合朗读的文本，费用自动统计 |
| 🔊 初版音频 | 内置 Edge 免费音色（微软神经语音，无需密钥）生成初版；GPT-SoVITS 引擎支持「初版 → 克隆音色换声」(VC)；OpenVINO 支持 NPU 端侧合成 |
| 🎛️ 混音工作台 | 语速/音调/音量/三段 EQ/背景乐音量/闪避/淡入淡出/段落间隔，滑块实时微调 |
| 🎚️ 分段级微调 | 每个分段可独立设置语速/音调/音量/EQ，渲染时先逐段生效、再叠加全局参数 |
| 📉 背景乐闪避 | 自动跟随人声（侧链压缩）或自定义关键帧闪避曲线（5 点，渲染时逐帧调制背景乐音量） |
| ▶️ 在线试听 | 浏览器内实时混音预览（SoundTouch 变速变调 + WebAudio EQ），零等待 |
| 👥 多人音色对比 | 同一文本用多个声音分别合成，A/B 连播对比，选出最合适音色 |
| 📑 章节书签导出 | 自动识别「第X章/回」切分章节；导出 CUE/LRC/JSON 索引或分章 mp3 ZIP |
| 🔋 NPU 端侧推理 | OpenVINO 引擎：本地 NPU/CPU 合成，免联网、免费用、不占 GPU（需自备模型） |
| 📚 作品管理 | 分段合成 → 拼接声音轨 → 渲染成品 mp3，在线播放/下载 |
| 💰 费用透明 | 云端引擎按字符/Token 自动统计费用，单价可在设置中调整 |
| 💾 本地存储 | 声音模型、文稿、分段音频、成品全部存于 `data/`（SQLite + 文件） |

## 技术架构

- **后端**：Python 3.10+ / FastAPI / SQLite / 线程任务队列（本地 GPU 任务串行、云任务并行）
- **前端**：Vue 3 + Vite + WaveSurfer.js（波形）+ SoundTouch.js（实时变速变调）+ WebAudio（EQ/混音）
- **音频处理**：FFmpeg（`imageio-ffmpeg` 自动下载静态二进制，无需系统安装）
- **硬件适配**：8GB 显存可跑 GPT-SoVITS 推理（约 4GB 占用）；32GB 内存足够处理数小时长音频；NPU 暂不参与（本地推理主要走 GPU 引擎独立进程）

## 快速开始

```bash
# 1. 后端
cd backend
pip install -r requirements.txt
python run.py                 # 启动后访问 http://127.0.0.1:8000

# 2. 前端（开发模式，可选；生产模式直接用后端内置页面）
cd ../frontend
npm install
npm run dev                   # http://127.0.0.1:5173 （已代理 /api 到 8000）
```

或使用 `start.bat`（一键启动后端并打开浏览器）。

**Windows 注意**：若 pip 报 GBK 编码错误，先执行 `set PYTHONUTF8=1` 再安装。

## 接入 GPT-SoVITS（本地声音克隆，已配置完成）

本机已完整配置（conda 环境 `gpt_sovits` + CUDA 版 PyTorch + 预训练模型）：

1. **一键启动**：双击 `F:\GPT-SoVITS-main\start_api.bat`（或根目录 `start_all.bat` 同时启动应用与引擎）
   - API 服务地址 `http://127.0.0.1:9880`，模型加载约 30~60 秒
2. `backend\.env` 已配置：
   ```
   GPT_SOVITS_URL=http://127.0.0.1:9880
   GPT_SOVITS_REF_DIR=F:/GPT-SoVITS-main/refs
   ```
3. 声音库页「引擎状态」显示 GPT-SoVITS **服务在线** 即可克隆：上传 10~60s 参考音频 + 对应文本 → 克隆 → 用克隆音色直接合成（新版 api_v2 已移除 /vc 音色转换端点，克隆音色合成效果等价）

**环境要点（踩坑记录）**：
- Python 3.10 conda 环境；PyTorch 2.10.0+cu126（本地 wheel 安装）
- **torchcodec 必须用 0.10.0**（与 torch 2.10 ABI 匹配；0.13+/0.16 会 DLL 加载失败）
- conda 装 FFmpeg 4.2.2（torchcodec 0.10 依赖 avcodec-58 系列 DLL）
- `pyopenjtalk`/`jieba_fast` 因缺 Windows SDK 无法编译，用兼容 stub（中文/英文/粤语合成不受影响，仅日文不可用）
- `TTS.py` 打了 `backend="soundfile"` 补丁（绕过 torchcodec 音频解码路径，更稳定）

## 微调训练（真·声音模型，从「模仿」到「真人朗读」）

零样本克隆只是带参考音频的模仿；**微调训练**会采集你的音色特征训练出专属声音模型，之后任意长度文本都能稳定像真人一样朗读。

- **数据准备**：声音库 → GPT-SoVITS 声音的「微调训练」面板 → 上传训练音频（可多选或 zip）。
  建议 1~3 分钟你自己的清晰朗读（几十条短句最佳）；想**混入名人音色**就把名人的公开音频一并放入，
  模型会自动融合多种音色特征，形成独特声音
- **一键训练**：选轮次（快速 5 / 标准 10 / 精细 20）→ 发起训练。流水线自动完成：
  切片 → FunASR 中文自动标注 → 文本音素/HuBERT/语义特征预处理 → SoVITS 音色模型训练 → GPT 语义模型训练
  （RTX 4060 上标准轮次约 30~60 分钟；首次训练需下载 ASR 模型）
- **训练产物**：`SoVITS_weights_v2/xxx.pth`（音色）+ `GPT_weights_v2/xxx.ckpt`（语义），自动记录到声音配置，
  之后合成自动加载微调模型
- **混合音色（推理级）**：声音库勾选其他克隆声音作为「辅助参考」，合成时即时融合双方音色（api_v2 多参考融合），
  无需训练即可试听混搭效果
- 训练用官方脚本（slice_audio / funasr_asr / prepare_datasets / s2_train / s1_train），与 GPT-SoVITS WebUI 同源；
  文本标注基于 ASR 自动转写，若个别句子识别有误可在 `F:\GPT-SoVITS-main\logs\<exp>\1-name2text.txt` 中手工修正后重新训练
- **Windows 训练补丁**（本机已打，勿覆盖）：`s2_train.py`/`s1_train.py` 单卡直训（绕开 torch 2.10 的 gloo/DDP
  Windows 崩溃）、`AR/data/bucket_sampler.py` 单卡回退、`s1_train.py` 放行 pathlib 的 weights_only 加载

## 歌曲词曲分离（人声/伴奏）

上传歌曲，一键分离出**人声（词）**与**伴奏（曲）**，全部本地免费、无需训练数据：

- **UVR5**（默认）：GPT-SoVITS 内置，模型权重已下载（HP2 通用 / BS-Roformer 高质量 / HP5 主唱 / VR-DeEcho 去回响）
- **Demucs**（可选）：Meta 开源 SOTA 模型（htdemucs），首次使用自动下载模型
- 分离结果本地存储，支持波形预览、在线播放、下载
- 玩法：人声轨可作为声音克隆的纯净素材；伴奏轨可作为有声读物背景音乐或翻唱混音素材
- 模型库可扩展配置云分离 API（预留，本地效果已优于多数付费 API）

## 音频润色（EQ/混响/压缩，提升声音饱满度）

上传自己朗诵的初稿音频，通过专业声学处理二次加工，让声音更饱满、更有质感：

- **5 段 EQ**：低频（厚度）/ 中低频（胸腔共鸣）/ 中频（清晰度）/ 中高频（临场感）/ 高频（空气感）
- **动态处理**：压缩器（阈值/比率/启动/释放/增益补偿）+ 去齿音 + 高通/低通滤波
- **空间感**：混响（干湿比 + 时长），让声音更圆润立体
- **降噪**：FFT 降噪清理录音底噪
- **响度标准化**：目标 LUFS 一键对齐，避免作品忽大忽小
- **实时试听**：浏览器内 Web Audio 即时处理（EQ/混响/压缩），渲染时用 FFmpeg 高精度输出
- 原声/润色波形对比、成品下载

## 接入 OpenVINO（NPU 端侧合成，可选）

1. 安装与转换模型：
   ```bash
   pip install openvino openvino-genai optimum[openvino]
   optimum-cli export openvino --model facebook/mms-tts-zho E:/models/mms-tts-zho-ov
   ```
2. 「设置」页填写模型目录（含 `openvino.xml`）与推理设备（默认 NPU，可选 CPU/GPU）。
   模型目录放 `voice.json`（`{"name":"我的端侧音色"}`）可自定义声音库显示名。
3. 声音库即可创建「OpenVINO（NPU 端侧）」声音用于合成。
   注意：该引擎为固定音色本地合成（无克隆功能），适合初版音频、隐私敏感与断网场景。

## 商用模型配置中心（模型库）

所有商用/本地模型统一在「模型库」页管理：**添加模型 → 填密钥 → 激活切换**，合成与润色自动使用当前激活的模型，随时来回切换对比性价比。

- **缺省模型**（首次启动自动预置，来自旧版设置）：Edge 免费音色（默认激活）、OpenVINO、MiniMax、Fish Audio、DeepSeek V4-Flash
- **预设模板**（一键追加，价格参考 2025 年市场价、可编辑）：MiniMax speech-02/hd、Fish、火山引擎、Azure、DeepSeek V4-Flash/Reasoner、通义 Qwen-Plus/Turbo、智谱 GLM-4-Flash（免费）、Kimi、豆包、GPT-4o-mini
- **激活规则**：语音类 / 润色类各只有一个模型处于激活态（单选自动切换）；删除时保护最后激活项
- **性价比估算**：输入预计字数，自动按单价估算各模型费用并升序排列（免费最优 / 最便宜 / 当前使用标记）
- **连通性测试**：LLM 发真实请求验证；语音类检查密钥配置完整性
- 密钥只存本机 SQLite，列表展示打码；旧 `设置` 页密钥自动迁移，无需重新配置

```
┌─ 模型库 ──────────────────────────────┐
│ 语音模型：Edge(免费,激活) MiniMax Fish │ ← 单选激活
│ LLM 模型：DeepSeek(默认) Qwen GLM Kimi │
│ 追加 → 选预设模板 → 填密钥 → 激活       │
│ 估算：10 万字 → 各模型费用升序对比       │
└───────────────────────────────────────┘
```

## 使用流程

1. **模型库**：确认激活的语音/润色模型（缺省为 Edge 免费 + 需自行激活 LLM）；需要商用模型时从预设模板一键添加并激活
2. **声音库**：克隆新声音 → 选择引擎 → 上传参考音频（10~60s 清晰人声）+ 填写对应文本 → 克隆
3. **文稿**：新建/导入 → （可选）选择风格 → LLM 润色（使用激活的 LLM 模型）→ 载入润色稿
4. **合成工作台**：选择文稿 + 声音 → 新建项目 → 生成声音轨（自动分段合成/换声、自动切分章节）
5. 拖动混音参数滑块 → 「实时试听（带效果）」在线预览；需要时展开「分段级微调」单独调整某段
6. 设置背景乐闪避（自动/曲线）→ 「渲染最终作品」→ 波形区在线播放 / 下载成品 mp3
7. **章节导出**：改名/调整章节范围 → 导出 CUE（CD 索引）/ LRC（歌词）/ JSON / 分章 mp3 ZIP
8. **多人对比**：在工作台底部选择多个声音 + 对比文本 → 生成对比 → A/B 连播选择最佳音色
